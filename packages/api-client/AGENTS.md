# packages/api-client

## Overview

`@swing-scan/api-client`: TypeScript types generated by openapi-typescript from `contracts/openapi.json`, plus an openapi-fetch client. The web app imports API types only from here. Filled in by scope feature 3 (contracts).

## Commands

```bash
make openapi      # write contracts/openapi.json from the FastAPI app
make gen-client   # regenerate the types in this package
```

## Conventions

- Generated files are committed and never edited by hand; CI reruns generation and fails on any diff.
- Read only for the FE and QA lanes. Changes arrive through a `contract-change` PR (doc 02 §15.6).
